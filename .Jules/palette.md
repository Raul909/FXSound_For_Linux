## 2026-06-03 - Add Keyboard and Screen Reader Accessibility to Custom Div Sliders
**Learning:** Custom div-based sliders require manual implementation of accessibility features to function correctly for keyboard-only and screen reader users: implement role="slider", tabIndex, appropriate ARIA state attributes (aria-valuenow, aria-valuemin, aria-valuemax), and onKeyDown handlers for directional arrow key manipulation. To ensure visible focus indicators without visual clashes, append :focus-visible and :focus-within pseudo-class selectors to existing :hover CSS rules while explicitly setting outline: none; on the browser's default focus ring.
**Action:** When building custom interactive components like sliders, always integrate role, tabIndex, ARIA attributes, and key down handlers directly into the track element, pairing them with :focus-visible styles that reuse hover styles.
