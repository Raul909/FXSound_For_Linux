## ⚡ Quick Start

The fastest way to install FXSound for Linux is via the **Snap Store** or by downloading the universal **AppImage**.

### 🌐 Official Downloads
Visit our official landing page to easily download the version for your system:
**[👉 fxsound-linux.pages.dev](https://fxsound-linux.pages.dev)**

### 📦 Snap Store (Ubuntu, Linux Mint, Manjaro, etc.)
```bash
sudo snap install fxsound-linux
```

### 🐧 AppImage (Universal Linux)
Download the `.AppImage` from the [Releases](https://github.com/Raul909/FXSound_For_Linux/releases/latest) page, make it executable, and run it.
```bash
chmod +x fxsound-linux_*.AppImage
./fxsound-linux_*.AppImage
```
