FXSOUND

A free, open-source audio enhancer for Linux — 10-band EQ, effects, presets, and real-time visualizer.

MIT License Tauri + Rust PipeWire / PulseAudio React 19

📦 AppImage Universal · All distros 🟠 .deb Ubuntu · Debian · Mint 🔵 .rpm Fedora · RHEL · openSUSE 🟣 Snap snapcraft.io ⭐ GitHub Releases All versions

FEATURES

🎚️
10-Band Parametric EQ
Fine-tune from 32Hz to 16kHz, ±12dB per band with biquad filters.
✨
5 Audio Effects
Fidelity, Ambiance, Dynamic Boost, 3D Surround, HyperBass.
🎵
10 Built-in Presets
Music, Movies, Gaming, Podcast, Bass Boost, and more.
📊
Real-time Visualizer
FFT-based spectrum display with smooth 60fps animation.
🔊
PipeWire / PulseAudio
Processes your system audio in real time — not just a UI mockup.
⚡
Native & Lightweight
Built with Tauri (Rust + React) for minimal resource usage.

INSTALL

AppImage (Universal)
wget https://github.com/Raul909/FXSound_For_Linux/releases/latest/download/fxsound-linux_1.0.0_amd64.AppImage
chmod +x fxsound-linux_1.0.0_amd64.AppImage
./fxsound-linux_1.0.0_amd64.AppImage
Debian / Ubuntu / Mint
wget https://github.com/Raul909/FXSound_For_Linux/releases/latest/download/fxsound-linux_1.0.0_amd64.deb
sudo dpkg -i fxsound-linux_1.0.0_amd64.deb
Fedora / RHEL / openSUSE
wget https://github.com/Raul909/FXSound_For_Linux/releases/latest/download/fxsound-linux-1.0.0-1.x86_64.rpm
sudo rpm -i fxsound-linux-1.0.0-1.x86_64.rpm
Snap
sudo snap install fxsound-linux
Arch Linux (AUR)
yay -S fxsound-linux
